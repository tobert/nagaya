Images

Text to image, img2img and inpainting, with LoRAs.

Qwen-Image takes no negative prompt, CFG 1, Euler, and no clip skip, spacing or LoRA. Write the trigger phrase yourself, such as fusal style. Previews show the steps and no picture.

The image sets the size: each side a multiple of 64 from 512 to 2048. The nagaya refuses another size and does not resize.

Steering

Make a control vector from two prompt sets, and try it against the plain model.

Each prompt is one user message with thinking off. The vector of each layer is the mean residual of Toward less the mean of Away (spec 11.12). For refusals, Toward holds requests that the model refuses, and Away holds requests that it answers. Then ablate the vector. A file loads into its box, and the page shows only the count of its lines.

Project

Trace

Project puts each layer of the vector through the unembedding: the tokens that it pushes up and down, and the rank of each end token. The J-Lens first moves each layer to the last layer, as the later layers would (docs/lab.md); the profile of the model names it. Trace runs the prompt plain, then with the vector and the operation above. Both runs use one seed, so the replies differ only by the vector. With no vector, only the plain run goes. A trace is a job of the engine, so the model must be ready (docs/lab.md). Choose a step: click a token or a chart.
